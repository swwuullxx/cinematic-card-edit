# Recipe: CapCut (mobile or desktop)

## Shortcut
Put **`presets/card_frame.png`** on an overlay track above all clips for the whole video. It's the black frame with the rounded hole already cut out. Scale each clip to fill the hole and skip steps 3–4 below.

## One-time setup (save as a template)
1. **New project → canvas 9:16**, background **black**.
2. Import a clip. Select it → **Basic → Scale** so it fills about 96% of the width.
3. **Mask → Rectangle (Square)** and set width/height to a 4:5 shape (about 1040×1330). Set **Round corners** to about 25–30 (CapCut's scale) and feather to 0.
4. Move the clip up slightly (Position Y about +30), so there's more black below than above.
5. **Adjust:** Brightness −25, Contrast +8, Saturation −10. Tap **Apply to all**.
6. Save the project as a **template** (or keep a "base" project and duplicate it).

## Captions
1. **Text → Auto captions**, then edit each caption so it holds **2–4 words** (use "Split").
2. Style: font **Inter / SF Pro / Helvetica**, Medium weight. Size is small (about 6–7 on mobile). White, **no stroke, no shadow, no background**.
3. Position: center, just below the middle of the card.
4. **Animation → In → "Blur"** (or "Fade in" plus a blur keyframe), duration **0.1–0.2s**. Out: **none**.
5. Select the styled caption → **Apply to all captions** (or save as a Text Template).

## Accent word
1. **Text →** type the word in CAPS. Use font **Anton / Bebas Neue**, very large, and stretch it vertically with the Scale-Y handle on desktop.
2. Add your texture image (clouds/chrome) as an **Overlay** above the text, sized to cover it.
3. On the texture overlay: **Blend → Mask/Clipping** (desktop: right-click → "Use as mask" / "Clipping mask"; mobile: set the overlay's blend to **Screen** over white text as a quick fake).
4. Place it exactly on the spoken word, about 0.5s long, with no animation. Cut the caption out under it.

## Cutting
- Hard cuts only, no transitions. Keep each clip **0.5–1.5s**.
- Cut on the gaps between phrases. Switch speaker → B-roll → speaker.
